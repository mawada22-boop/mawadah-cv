# السيرة الذاتية — مودة سمير كاشقري

سيرة ذاتية رقمية باللغة العربية، بتصميم متجاوب، لأخصائية المعلومات **مودة سمير كاشقري**.

- **الموقع:** [https://mawada22-boop.github.io/mawadah-cv/](https://mawada22-boop.github.io/mawadah-cv/)
- **النسخة PDF:** [mawadah-cv.pdf](mawadah-cv.pdf)

## المحتوى

- نبذة مهنية في ثلاثة أسطر.
- المؤهل العلمي: ماجستير الذكاء الاصطناعي (قيد الدراسة) — الجامعة الإسلامية بمينيسوتا، وبكالوريوس علم المعلومات — جامعة طيبة.
- خمس مهارات أساسية، إضافة إلى مهارات مساندة.
- الدورات التدريبية واللغات ومجالات الاهتمام.
- بيانات التواصل.

## التشغيل محليًا

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.
